## #4 Incident Journal Entry: Suspicious File Hash Investigation (Alert A-2703)

- **Date:** October 20, 2026
- **Entry:** 4
- **Description:** Investigating a suspicious file hash alert generated by an Intrusion Detection System (IDS) following a phishing attempt (`bfsvc.exe`). This entry covers the *Detection and Analysis* phase of the NIST Incident Response Lifecycle.
- **Tool(s) Used:** VirusTotal & Incident Response Playbooks. VirusTotal is an investigative threat intelligence platform used to analyze file hashes, domain reputation, and URLs against multiple security engines to confirm indicators of compromise (IoCs).

### The 5 W's

- **Who:** An unknown external threat actor spoofing identity details (`76tguyhh6tgftrt7tg.su`).
- **What:** An employee received a phishing email containing a password-protected malicious executable attachment (`bfsvc.exe`) with the SHA-256 hash `54e6ea47eb04634d3e87fd7787e2136ccfbcc80ade34f246a12cf93bab527f6b`.
- **Where:** An employee workstation within the corporate network (`hr@inergy.com`).
- **When:** July 20, 2022, at 09:30:14 AM / 1:20 p.m. alert detection.
- **Why:** The attacker used targeted social engineering and payload encryption to bypass perimeter email filters and trick the user into executing the file.

### Additional Notes

- Following the Phishing Response Playbook, the file hash confirmed a 44/64 detection ratio on VirusTotal. The ticket was successfully updated to **Escalated** for Tier-2 SOC containment.

## Reflections & Course Notes

- **Were there any specific activities that were challenging for you? Why or why not?**
  Working with `tcpdump` on the command-line interface was the most challenging activity. Learning the precise command syntax and filtering flags required careful attention to detail and multiple attempts, but repeating the exercise built strong confidence in CLI navigation.
- **Has your understanding of incident detection and response changed since taking this course?**
  Yes, my perspective has evolved significantly. I now understand incident response as a structured, lifecycle-driven discipline (NIST) where documentation, standardized playbooks, and structured logging are just as vital as technical investigation tools.
- **Was there a specific tool or concept that you enjoyed the most? Why?**
  I enjoyed network packet analysis using Wireshark alongside threat intelligence lookup in VirusTotal. Being able to inspect raw network flows and immediately cross-reference cryptographic file hashes against global threat databases provided an exciting, hands-on SOC experience.
