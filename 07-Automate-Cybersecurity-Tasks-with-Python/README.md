# 🐍 Course 7: Automate Cybersecurity Tasks with Python

## 📌 Course Overview

**Automate Cybersecurity Tasks with Python** introduces programming concepts and demonstrates how Python can support everyday cybersecurity work. The course progresses from foundational syntax to functions, modules, strings, lists, regular expressions, and file processing.

This section of my portfolio brings together course notes and a practical access-list automation exercise. The project uses Python to read an allow list, remove IP addresses that are no longer authorized, and update the file with the revised list.

## 🎯 What I Learned

- **Use Python fundamentals:** Work with variables, data types, conditional statements, and iterative statements.
- **Write readable code:** Use clear naming, comments where helpful, and consistent structure to make scripts easier to understand and maintain.
- **Use functions and modules:** Apply built-in and user-defined functions and organize reusable code with modules.
- **Work with strings and lists:** Search, split, transform, and process collections of data.
- **Search for patterns:** Use regular expressions to identify patterns within text.
- **Read and update files:** Open files safely, parse their contents, and write updated information.
- **Debug Python code:** Use a systematic approach to identify and correct errors.
- **Automate security tasks:** Apply programming to repetitive work such as reviewing access lists and processing security data.

## 🧪 Practical Exercise

Created a Python algorithm to update an IP address allow list. The script reads addresses from a file, converts the contents into a list, compares entries against a removal list, removes addresses that should no longer have access, and writes the revised list back to the file.

This exercise demonstrates how file handling, list operations, loops, conditionals, and string methods can be combined to automate a security-related task.
